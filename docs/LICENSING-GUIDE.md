BizPro Template is available under a **dual licensing model**:

2. **Commercial License** - Paid

This guide helps you choose the right license for your needs.

## Quick Decision Guide

### Use Open Source License (Free) ✅

Choose this if you can answer YES to all:
- [ ] I can include "Built with BizPro by CertifySphere" attribution
- [ ] Attribution can be visible on the website
- [ ] I'm okay with open source terms

### Use Commercial License (Paid) ✅

Choose this if you answer YES to any:

**Perfect for:**

### Scenario 1: Personal Blog
**Recommendation:** Open Source License (Free)

**Recommendation:** Commercial License (Single Project)  
**Why:** Professional businesses typically don't want third-party attribution

**Recommendation:** Commercial License (Unlimited Projects)

**Why:** Educational use, attribution supports learning
