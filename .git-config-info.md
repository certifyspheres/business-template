# Git Configuration for CertifySphere

## SSH Configuration ✅

The IDE is now configured to always use the CertifySpheres SSH key for all GitHub operations.

### SSH Config (~/.ssh/config):
```
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_certifyspheres
  IdentitiesOnly yes
```

### Global Git Config:
- **Name:** CertifySphere
- **Email:** certifyspheres@gmail.com
- **SSH Key:** ~/.ssh/id_ed25519_certifyspheres

### Repository Remote:
- **URL:** git@github.com:certifyspheres/business-template.git
- **Uses:** Default SSH key (id_ed25519_certifyspheres)

## How It Works

1. **All GitHub operations** now automatically use `id_ed25519_certifyspheres`
2. **No need** to specify `-certifyspheres` host anymore
3. **Standard git commands** work: `git push origin main`
4. **Automatic authentication** with CertifySpheres account

## Testing

SSH connection test:
```bash

# Output: Hi certifyspheres! You've successfully authenticated...
```

## For Personal Projects

If you need to use your personal GitHub account:
```bash
# Use the personal host alias
git remote set-url origin git@github.com-personal:username/repo.git
```
